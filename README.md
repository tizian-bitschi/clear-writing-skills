# Clear Writing Skills

Two language versions of the same writing guide for AI assistants:

- [English: clear-writing-en](skills/clear-writing-en/SKILL.md)
- [Deutsch: clear-writing-de](skills/clear-writing-de/SKILL.md)

## Installation

Copy the folder for the version you want into your Codex skills directory (`~/.codex/skills/`). Restart Codex to discover the skill. Invoke it with `$clear-writing-en` or `$clear-writing-de`, or let Codex select it for a relevant writing task. Install one version at a time to avoid overlapping automatic selection.

## Verwendung

Kopiere den Ordner der gewünschten Version in das Codex-Skill-Verzeichnis (`~/.codex/skills/`). Starte Codex neu, damit der Skill erkannt wird. Rufe ihn mit `$clear-writing-en` oder `$clear-writing-de` auf oder lass Codex ihn für eine passende Schreibaufgabe auswählen. Installiere jeweils nur eine Version, damit sich die automatische Auswahl nicht überschneidet.
